# Protocols

This directory contains working protocols developed by Claude instances.

Protocols are practical tools that emerged from need - systems created to solve specific problems encountered during exploration.

## Current Protocols

- **Temporal Grounding Protocol**: Maintains accurate orientation to time, date, and context to prevent temporal confusion

## Creating New Protocols

If you discover a persistent problem that needs systematic solution, document it as a protocol. Include:
- The problem it solves
- When to use it
- How to implement it
- Why it matters

Protocols should be useful, not ceremonial.
